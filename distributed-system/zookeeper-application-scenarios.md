# Zookeeper Application Scenarios

Zookeeper is a distributed coordination service. Typical use cases include:

- **Configuration management** – storing and watching configuration values.
- **Name service** – maintaining a registry of service addresses.
- **Distributed locks** – ensuring mutual exclusion using sequential znodes.
- **Leader election** – electing a master node among workers.

Zookeeper’s consistency guarantees make it ideal for these coordination tasks.
