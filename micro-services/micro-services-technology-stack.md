# Microservices Technology Stack

Typical components of a microservices stack:

- **Service registry** (Eureka, Consul) – for service discovery.
- **Configuration server** (Spring Cloud Config) – centralised configuration.
- **API gateway** (Zuul, Spring Cloud Gateway) – routing, filtering and security.
- **Communication protocols** – REST/HTTP, gRPC, message queues.
- **Observability tools** – Zipkin, Prometheus, Grafana.

This stack provides the building blocks for a robust microservice architecture.
