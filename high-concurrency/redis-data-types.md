# Redis Data Types

Redis supports several basic and advanced data structures:

- **String** – stores binary data up to 512 MB.
- **List** – linked lists of strings, supporting push/pop operations.
- **Hash** – maps fields to values; used to represent objects.
- **Set** – unordered collections of unique strings.
- **Sorted Set** – like a set but with scores for ordering.
- **Bitmap**, **HyperLogLog** and **Streams** provide additional functionality.

Choosing the right data type simplifies code and improves performance.
