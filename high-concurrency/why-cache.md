# Why Use Caching?

Caching stores frequently accessed data in memory to speed up response times and reduce load on databases and back‑end services. Benefits:

- **Reduced latency** – memory access is orders of magnitude faster than disk access.
- **Reduced database load** – fewer queries improve database performance and scalability.
- **Improved user experience** – faster responses lead to better user satisfaction.
