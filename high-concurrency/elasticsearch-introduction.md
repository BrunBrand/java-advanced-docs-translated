# Introduction to Elasticsearch

Lucene provides powerful full‑text search but is hard to use directly. Elasticsearch wraps Lucene with REST and Java APIs and supports distributed deployments. Core concepts include:

- **Near real‑time** – indexed documents are searchable within seconds.
- **Documents** – each record is a JSON document.
- **Indices and shards** – an index is like a database; it is split into shards and replicas for scalability.
